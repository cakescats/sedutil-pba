# CakesCats PBA — поддерживаемый PBA-образ sedutil для OPAL-дисков

Предзагрузочный образ (PBA) для SSD с аппаратным шифрованием (TCG OPAL 2.0,
self-encrypting drive). Это форк [sedutil](https://github.com/Drive-Trust-Alliance/sedutil):
официальные образы последний раз выходили в 2021 году (1.20) и часто зависают
на новых ноутбуках ([sedutil#404](https://github.com/Drive-Trust-Alliance/sedutil/issues/404)).

## Чем отличается от DTA 1.20

- Свежий стек: Buildroot 2026.02 LTS и ядро 6.18 LTS. Сборка воспроизводимая, через GitHub Actions, с опубликованными хэшами.
- **Несколько дисков с разными паролями.** Каждый пароль пробуется на всех заблокированных дисках. Потом 3 секунды (настраивается) можно нажать клавишу и ввести ещё один пароль для оставшихся.
- **Разделы со своими паролями.** `sedutil-cli --setupPartitionRanges` запирает выбранные разделы отдельным паролем (диапазоны OPAL), а PBA спрашивает эти пароли по очереди. Пароль Admin1 остаётся главным. Подробнее в [docs/partitions.md](docs/partitions.md).
- Хэш пароля по умолчанию такой же, как в sedutil 1.x: PBKDF2-SHA1, 75000 итераций. Уже настроенные диски работают без перенастройки. Есть PBKDF2-SHA512 с настраиваемым числом итераций.
- Сервисная консоль (бывший `debug`) настраивается явно: включена, выключена или закрыта отдельным паролем. В hardened-образе её нет.
- Сеть не поднимается. Перезагрузка в ОС тёплая (warm reset), как в рабочем FIXED-образе.
- Для машин, которые зависают при загрузке, есть пункт меню с `nosmp`: нажать Esc при старте.
- Логотип и цвета CakesCats.

## Установка

Коротко:

1. Запишите PSID с наклейки диска.
2. Проверьте образ с флешки.
3. Настройте диск командами `sedutil-cli --initialSetup`, `--loadPBAimage`, `--setMBREnable on`, `--enableLockingRange 0`.

Подробно, от проверки диска до восстановления, — в [руководстве пользователя](docs/manual.ru.md).

Для SHA-512 добавьте ключ `-H sha512` к командам sedutil-cli и пропишите
`hash = sha512` в конфиге образа.

## Сон

PBA запускается только при холодной загрузке:

- Гибернация (S4) и Fast Startup идут через PBA и работают.
- S3 и Modern Standby работают, если диск во сне не теряет питание.

Как проверить на своей машине — в [docs/sleep-matrix.md](docs/sleep-matrix.md).

## Для компаний

Интеграция с корпоративными системами — в
[cakescats/sedutil-opal-enterprise](https://github.com/cakescats/sedutil-opal-enterprise):

- вход через корпоративный SSO (Entra ID, Okta, Google, Keycloak);
- развёртывание и конфигурация через MDM (Intune, Ansible);
- центральный сервер с правами доступа по машинам и журналом аудита.

Поддержка в самом PBA есть в обычном образе и выключена, пока её не
настроит билдер ([docs/sso.md](docs/sso.md)).

## Сборка

scripts/build.sh --profile default
